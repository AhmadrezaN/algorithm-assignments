## CPU Scheduling
#### Problem Description
You are designing a CPU scheduler for an operating system with $n$ programs (each with a specific execution time) and $k$ CPU cores. Every program must be assigned to exactly one core, and the processing load of a core is the sum of execution times assigned to it. The objective is to assign the programs using **backtracking or branch and bound** to minimize the maximum processing time among all cores (makespan minimization).
* **Time Limit:** 1 second
* **Memory Limit:** 256 MB
* **Constraints:** $1 \le k \le n \le 12$, $1 \le \text{time}_{process} \le 10^{7}$

### Approach
The solution uses a **Backtracking and Branch-and-Bound** strategy (`CPUScheduling` function):
1. **Recursive Exploration:** The algorithm recursively attempts to assign each process `f` to every available core `k`.
2. **Pruning (Branch and Bound):** A set (`S`) and a current best minimum makespan (`min`) are maintained to prune redundant branches (e.g., symmetric core states) and paths where a core's load already exceeds the current best upper bound.
3. **State Restoration:** Backtracking is performed by subtracting the process time upon returning from recursion, allowing exploration of alternative assignment paths.

#### Complexity Analysis
* **Time Complexity:** $O(k^n)$ in the worst-case scenario for exhaustive search, heavily optimized by branch-and-bound pruning and state uniqueness checks via sets.
* **Space Complexity:** $O(n + k)$ auxiliary space for recursion stack depth and tracking the load states across the $k$ cores.

#### C++ Solution Highlights
```cpp
long long CPUScheduling(long long Pros[], long long core[], int k, int f, int n, long long min, int idx) {
    if (f == n || core[idx] > min) {
        return core[idx];
    }
    std::set<long long> S;
    for (int i = 0; i < k; i++) {
        if (S.find(core[i]) == S.end()) {
            core[i] += Pros[f];
            // Pruning and recursive call...
            long long sub = CPUScheduling(Pros, core, k, f + 1, n, min, jdx);
            if (sub < min) min = sub;
            core[i] -= Pros[f];
            S.insert(core[i]);
        }
    }
    return min;
}

```
## Context-Free Grammar
### Problem Description
Given a context-free grammar (CFG) consisting of derivation rules where variables are represented by uppercase letters and terminal letters by lowercase letters, write a program to determine whether a given target word can be generated by the grammar. The solution must be implemented using **backtracking or branch and bound** techniques, outputting `yes` if the word belongs to the language and `no` otherwise.
* **Time Limit:** 1 second
* **Memory Limit:** 256 MB

#### Approach
This problem is solved using a **Backtracking and Branch-and-Bound** approach utilizing a stack-based search (`Q`):
1. **Grammar Parsing:** Rules are ingested and parsed line-by-line into a structured representation where non-terminals map to their possible expansions.
2. **State Space Tree Exploration:** The search starts from the start symbol `S` (the root variable) and explores valid string substitutions recursively or iteratively via a stack.
3. **Pruning (Branch and Bound):** A pruning check (`temp.length() > goal.length()`) instantly terminates branches where the current string length exceeds the target word length, preventing infinite loops and unnecessary expansions.

#### Complexity Analysis
* **Time Complexity:** Exponential $O(b^d)$ in the worst case (where $b$ is the branching factor of grammar choices and $d$ is the depth), heavily mitigated by length-bound pruning.
* **Space Complexity:** $O(b^d)$ auxiliary space for the stack holding search paths and string allocations during derivations.

#### C++ Solution Highlights

```cpp
Q.push(Rules[0][0]);

    }
```

## Memory Parasites

### Problem Description
Mr. Sanchez returns home to find an unusually large number of people and suspects that memory-parasite aliens (parasites) have infiltrated his family. Humans always tell the truth, whereas parasites may either tell the truth or lie. Given a statements matrix where each person $i$ gives a statement about person $j$ (`1` for human, `0` for parasite, `2` for no opinion), the objective is to find the maximum possible number of humans in the house such that their statements are consistent.
* **Time Limit:** 1 second
* **Memory Limit:** 256 MB
* **Constraints:** $2 \le n \le 20$

#### Approach
This problem is solved using a **Backtracking** search strategy (`Max` function):
1. **State Space Tree:** The algorithm explores all possible subsets of individuals being human or parasite by recursively branching on each person $k$.
2. **Validation (Base Case):** Once all individuals are assigned, it validates whether the chosen group of humans complies with consistency rules: any statement made by a chosen human must match the actual status of the target person.
3. **Maximized Counting:** It tracks and returns the maximum number of humans that satisfy all consistency constraints.

#### Complexity Analysis
* **Time Complexity:** $O(2^n \cdot n^2)$ in the worst case to check all combinations of subsets for $n$ people, feasible given $n \le 20$.
* **Space Complexity:** $O(n^2)$ auxiliary space to store the adjacency statement matrix and tracking marks.

#### C++ Solution Highlights

## Alphabetrium
#### Problem Description
Welcome to Alphabetrium, a city where people communicate by transforming words from a dictionary such that every adjacent pair of words differs by exactly one character. Given a starting word, a target word, and a dictionary of $n$ words, the objective is to find a valid sequence of word transformations (a word ladder) from the start word to the target word.
* **Time Limit:** 1 second
* **Memory Limit:** 256 MB
* **Constraints:** Word lengths $\le 8$, number of dictionary words $2 \le n < 100$

#### Approach
This problem is solved using a graph traversal strategy implemented via **Backtracking / State Search** with a stack:
1. **Word Relationship Checking (`isDiffis1`):** Helper function verifies if two words differ by precisely a single character.
2. **State Stack Exploration:** Using a stack, the algorithm explores unvisited dictionary words that meet the single-character difference condition, keeping track of parent pointers to reconstruct the path.
3. **Path Reconstruction (`Print`):** Once the target goal word is found, recursion is used to backtrack through the parent indices and print the full transformation sequence.

#### Complexity Analysis
* **Time Complexity:** $O(n \cdot L)$ where $n$ is the number of dictionary words and $L$ is the length of the words, due to checking character-by-character differences across dictionary entries.
* **Space Complexity:** $O(n)$ auxiliary space to store the word array, tracking marks, and recursion/stack traversal depth.

#### C++ Solution Highlights
```cpp
bool isDiffis1(std::string A, std::string B) {
    if (A.length() != B.length()) return false;
    int diff = 0;
    for (int i = 0; i < A.length(); i++) {
        if (A[i] != B[i]) diff++;
    }
    return (diff == 1);
}
```
